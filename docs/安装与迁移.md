# 安装与迁移

适用版本：`v0.1.0-beta.1`。节点克隆与 ZIP 安装入口见 [README](../README.md#安装)。目标环境为已经能运行 MiniMax H3 的 Windows 电脑；未承诺其他系统或任意新版节点的兼容性。

## 先确认目标环境

先在目标电脑使用原有 H3 工作流完成一次正常运行，再安装本节点。插件包不包含 H3、SelfLift、ASR、人声分离或 Qwen 模型，也不替换已有 GPU 环境。

下表记录 2026-10-25 本机参考状态，用于核对节点接口；不要求把能正常运行的目标环境全部升级或降级到这些版本。仓库可能继续更新，最新代码不一定保留同一工作流接口。

| 组件 | 来源 | 本机参考版本 / 提交 |
| --- | --- | --- |
| ComfyUI 核心 | [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI) | `0.42.0` / `bef11fcbfa8d772678e2ad00b1294c63eb3e5da7` |

当前 TY 顺序生成必须有 VHS 输出节点。SelfLift Avatar、BFSNodes 和 KJNodes 是随附 SelfLift 示例的额外依赖；使用其他已有长音频工作流时，按其节点需求安装。SelfLift 需要的是表中的 **`selflift-Avatar`**，不要仅凭相近名称安装成其他项目。

工作流还依赖核心提供的 H3 加载、参考视频、文本编码、采样与解码节点，包括 `LoadLoraModel`、`BlockSparseAttention` 等。在本机参考环境中这些位于 ComfyUI 的 `comfy_extras`，并非本插件附带的独立自定义节点。若导入后缺失，应先核对目标核心的 H3 接口。

## 首次安装

1. 使用 README 中的克隆命令，或下载 `v0.1.0-beta.1` 预发布附件/仓库 `main` 分支的源码 ZIP。
2. 确保插件位于 `ComfyUI/custom_nodes/ComfyUI-H3-TY-LongVideo`，下一级就是 `__init__.py`、`nodes.py`、`web` 等。源码 ZIP 解压后须改为这个固定目录名，不要出现双层同名文件夹。
3. 打开 PowerShell，进入该插件目录，确认当前 ComfyUI 实际使用的 Python。便携版通常使用其随附 Python，虚拟环境版使用对应虚拟环境的 Python；不要默认使用系统 `python`。
4. 用该 Python 检查环境并安装依赖：

```powershell
$ComfyPython = "<目标 ComfyUI 使用的 python.exe 完整路径>"
& $ComfyPython -c "import sys; print(sys.executable)"
& $ComfyPython -c "import torch, torchaudio, numpy, PIL, aiohttp; print('torch', torch.__version__); print('torchaudio', torchaudio.__version__); print('CUDA', torch.version.cuda); print('cuda_available', torch.cuda.is_available())"
& $ComfyPython -m pip install -r .\requirements.txt
& $ComfyPython -c "import faster_whisper, soundfile; print('ASR / SoundFile imports OK')"
```

将第一行占位文字替换为实际路径。`requirements.txt` 保留 `faster-whisper==1.2.1`，并声明 SoundFile；缺包时插件会报错，不会自动安装依赖。Torch、torchaudio、NumPy、Pillow、aiohttp 复用目标 ComfyUI 环境。若检查报错，先修复该环境对应的依赖或 DLL，不要直接安装另一套 Torch/CUDA。

5. 确认 FFmpeg 和 ffprobe 可用，再重启**目标电脑**的 ComfyUI 并刷新浏览器。
6. 导入 [SelfLift 预发布示例](../examples/TY_ShotPlanner_SelfLift_迁移版_20261025.json)，重新选择本机素材和模型。视频上传与截取功能已包含在本节点中，无需另装 TY 插件。

## FFmpeg 与 ffprobe

若目标机没有工具，从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)的 **Windows EXE Files** 入口选择 Windows 构建，解压后确认 `bin` 目录内同时有 `ffmpeg.exe` 与 `ffprobe.exe`，再按下列方法配置路径。已有可用工具时直接复用。

两者都需要可用；只有 `ffmpeg.exe` 而没有 `ffprobe.exe` 仍会导致分析失败。可将工具所在目录加入启动 ComfyUI 的进程所继承的 `PATH`：

```powershell
Get-Command ffmpeg.exe, ffprobe.exe
ffmpeg.exe -version
ffprobe.exe -version
```

若启动器无法继承 PATH，可在**启动 ComfyUI 的同一环境**中设置：

```powershell
$env:FFMPEG_PATH = "<ffmpeg.exe 完整路径或所在目录>"
$env:FFPROBE_PATH = "<ffprobe.exe 完整路径或所在目录>"
```

新开另一个 PowerShell 设置变量不会改变已运行的 ComfyUI。插件也会尝试发现常见工具目录，但迁移时应明确核对两项配置。浏览器预览取决于浏览器支持的编码；预览失败不等于 FFmpeg 无法读取。需要预览时可使用 H.264 视频与 AAC 音频的 MP4 副本。

## 模型与联网

| 用途 | 行为 |
| --- | --- |
| H3、LoRA、VAE、CLIP/文本编码器与 SelfLift | 使用目标机现有安装，按工作流逐个选择，不随本包复制。 |
| ASR | 首次分析按需下载 `large-v3-turbo`，缓存至 `ComfyUI/models/faster-whisper`。 |
| 唱歌人声分离 | `singing` 且未传入独立 `vocals` 时，按需下载 HDEMUCS，约 319 MiB。Shot Planner 从视频提取音轨，唱歌模式会走此路径。 |
| LongVideo 可选 Qwen | 只有旧长音频的 Qwen 导演或扩写路径需要，见[长音频功能](长音频功能.md)。 |

当前 Shot Planner 的本地规则与 `final` 提示词路径不需要 Qwen GGUF 或 llama.cpp。不要因此删除 H3 自身必须的 CLIP/文本编码器。

首次下载需要相应模型来源可访问并有足够磁盘空间。ASR 缓存在 `ComfyUI/models/faster-whisper`，HDEMUCS 缓存在 `ComfyUI/models/TYH3LongVideo/hdemucs_high_trained.pt`；分析日志位于相应项目内的 `state/asr.log`。

本仓库不包含模型或运行时二进制。后续可复用本机缓存，但不能仅凭源码仓库保证完全离线运行。

## 已有 TY 插件的更新

1. 等当前任务完成并关闭目标 ComfyUI。
2. 备份旧 `ComfyUI-H3-TY-LongVideo` 到 **`custom_nodes` 之外**，记录旧版本和已用 Python。
3. 保存旧工作流；如需回滚，再备份 `output/TYH3LongVideo` 与 `user/default/TYH3LongVideo`。
4. 将新版本放回同一个插件目录，安装本版本依赖。不要把新旧插件同时留在 `custom_nodes`，也不要只覆盖部分 Python/前端文件。
5. 原有 `runtime_config.json` 与运行时二进制属于本机配置，仓库不带。只用 Shot Planner 时无需恢复；用旧长音频 Qwen 时按该功能文档重新检查并安装目标机运行时。
6. 启动 ComfyUI，刷新前端，再导入预发布示例测试。安装插件不会自动迁移或清空旧项目。

首次安装后节点搜索应能找到 `TY Shot Planner`、`TY H3 长视频 · 音频分析与顺序生成`、`TY H3 长视频 · Qwen 全片导演任务`。标识分别为 `TY_ShotPlanner`、`TY_H3LVUnified`、`TY_H3LVDirectorTask`。

## 目标机首次验收

1. 核对没有缺失节点，所有模型输入均选中存在的文件，参考图已重新选择。
2. 上传一段带声音的短视频；确认预览/文件选择对应新素材，按钮为“分析并分段”。
3. 点击分析，等下载和识别完成，检查项目时长、分段和音轨对应当前素材。
4. 检查切点后“保存并确认”，只点击一段的“仅生成本段”，检查采样器实际运行且生成视频可播放。
5. 批量生成前，验证参考图、人物替换、声音和画幅；生成完成后再检查合成。
6. 专项复核“不重新分析，直接重新生成本段”：应提交新采样任务并产出新版本。这是当前 SelfLift 修复仍需补做的实机验证。

以上是目标机操作清单，不代表本预发布已执行异机实跑。沿用的离线检查记录与未覆盖项见[验证摘要](../验证摘要.md)。

## 回滚

停止目标 ComfyUI，把新插件移到 `custom_nodes` 外，再将备份的旧插件放回原路径；恢复旧工作流及必要的项目/规则备份，使用旧环境启动并刷新浏览器。不要在新旧插件同时存在时排查问题。

依赖安装改变了 Python 环境时，仅替换插件目录不一定恢复依赖版本。需要完整回滚的目标环境，应在更新前保留该 Python 环境备份。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 导入后显示红色缺失节点 | 核对上表仓库、目标核心 H3 支持和启动日志，避免安装相似名称的 SelfLift。 |
| 模型下拉为空或提示文件不存在 | 模型不随包提供；重新选择目标机模型，并核对其类型与目录。 |
| 分析失败或持续等待 | 检查视频是否有音轨、FFmpeg/ffprobe、ASR 下载网络及项目内 `state/asr.log`。 |
| `numpy`、`soundfile`、ASR 无法导入 | 核对安装命令所用 Python 与 ComfyUI 一致，再检查依赖和 DLL。 |
| Torch / torchaudio / CUDA 错误 | 检查目标 H3 环境已有组合；不要用通用升级命令覆盖 GPU 依赖。 |
| 上传后按钮或预览仍旧 | 确认只有一份 TY 插件，已重启载入新版后端并刷新前端；核对当前视频选择和项目绑定。 |
| 不重新分析时单段重做未进入采样器 | 核对已重载预发布后端，查看新任务和实际种子；保留证据，按阶段说明记录未通过项。 |
| 不同电脑没有原项目 | 仓库只包含节点和空状态示例，旧项目与素材需单独迁移。 |
