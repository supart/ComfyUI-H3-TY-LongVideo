# 长音频数字人功能

适用版本：`v0.1.0-beta.1`。本插件保留 `TY_H3LVUnified`（TY H3 长视频 · 音频分析与顺序生成）与 `TY_H3LVDirectorTask`（TY H3 长视频 · Qwen 全片导演任务），用于歌曲或口播音频分段、镜头规划、逐段生成与原音频合成。仓库附带 Shot Planner SelfLift 预发布示例，未附旧长音频示例；以下用于维护已有长音频工作流。

## 准备与接线

将歌曲或口播的完整 `AUDIO` 接入统一节点的 `audio`；已有独立人声时可接 `vocals`。使用 H3 Ref2VA 的参考图与参考视频输入，在目标机选择对应 H3、LoRA、VAE、文本编码器等模型。

顺序生成工作流需保留一个 `TY_H3LVUnified` 和一个 [VHS Video Combine](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) 输出节点。长音频节点输出当前 `segment_index` 的音频、简报、生成帧数、文件名前缀和六个图像槽位，由控制器顺序提交各段。当前 TY 不支持用上游新增的原生视频保存链路替代它。

旧提示词工作流可以保留：

```text
segment_brief → 提示词小助手 → H3 提示词
```

提示词小助手属于旧路径的额外依赖，不随本仓库安装。本插件自带的本地 Qwen 全片导演不要求画布存在外部 `QwenH3PromptLocal` 节点，也不要求安装 `ComfyUI_Qwen_H3_Prompt`，更不需要上游新增的外部 API 服务配置。

## 参考图

默认沿用画布的参考图。审核面板的“图像素材库”可集中上传多张图，每段可单独指定、调整顺序并填写素材说明，例如“图1是人物，图2是场景”。默认参考图张数作用于没有单独配置的分段。

H3 参考图输入的可用槽位以画布接线为准，最多六张。需要每段独立数字人和背景/PPT时，将统一节点的 `image_1`、`image_2` 直接接至 H3 的 `ref_image_0`、`ref_image_1`；后四个图像输出按需使用。每段未选择新素材的槽位沿用节点外部输入。

使用旧外部 Qwen 路径时，同一组参考图应按同一顺序供扩写与 H3 使用。修改参考图、素材说明或默认张数后，保存并确认，再重生成受影响分段。

## 模式与参数

| 设置 | 作用 |
| --- | --- |
| `mode=singing` | 唱歌模式，未提供 `vocals` 时分离人声；按规则安排景别和镜头变化。 |
| `mode=speaking` | 口播模式，沿用参考构图与人物位置，固定机位。 |
| `mode=speech_light` | 居中演讲，人物正面居中，保持胸像或半身中景，不主动安排推拉、摇移或重新取景。 |
| `target_seconds` / `max_seconds` | 目标片长与允许最长片长；切点仍以分析结果和审核为准。 |
| 镜头活跃度 / 最远允许景别 | 控制唱歌模式的镜头规划；不用于覆盖居中演讲稳镜规则。 |
| `llm_model` / `vision_model` | 本插件 Qwen 的完整 GGUF 模型名及多模态投影文件。 |
| `think_mode` / `reasoning_effort` | Qwen 的思考与推理设置。 |
| `seed` / `max_tokens` | 本插件 Qwen 的规划随机种子及输出预算，不等于 H3 采样种子。 |
| `video_sample_frames_per_sec` | 参考视频采样帧数，用于按时间组织视觉信息。 |
| `force_unload_model` | Qwen 调用结束后释放其模型占用。 |

在“运镜规则：查看与修改”中编辑本地规则。保存规则只影响后续规划；需要新分段项目时重新分析。它不会重做已经生成的视频，也不保证模型逐像素锁定人物或背景。

## 分析、审核与生成

1. 加载音频和参考图，设置模式与分段时长，执行分析并打开审核面板。
2. 切换原曲/人声试听，逐段检查句尾与气口。可拖动切点、编辑镜头方案和素材说明，完成后“保存并确认”。
3. 使用本地规则即可沿规则生成；需要 Qwen 全片设计时，按下节配置后运行“Qwen 全片分镜设计”，人工检查并确认导演草稿。
4. 先“仅生成本段”检查效果，再“批量生成”。控制器顺序生成各段，完成后配回原音频。
5. 可在当前段完成后暂停、继续后续任务，或“重新生成本段”“恢复上一版”“仅重新合成”。

波形支持选择当前段或切点附近放大、拖动切点和横向浏览；也可用时间输入检查边界。“导出分段时长”可导出当前草稿的分段时间表。

修改切点会影响相邻片段，修改镜头或参考素材会使对应片段需要更新。继续生成沿用项目保存的设置，重新生成使用当前画布快照；生成前确认使用的是所需版本。

## 可选 Qwen 运行时

只有选择长音频 Qwen 导演或相关扩写路径时才需要下面步骤。Shot Planner 本地规则和完整 `final` 提示词不需要该运行时；H3 自身的文本编码器仍按 H3 要求保留。

在插件目录，使用目标 ComfyUI 的 Python 先检查：

```powershell
$ComfyPython = "<目标 ComfyUI 使用的 python.exe 完整路径>"
& $ComfyPython .\install_runtime.py --dry-run
```

核对它识别的系统与后端后，再使用现有脚本安装：

```powershell
& $ComfyPython .\install_runtime.py
```

脚本会按现有安装逻辑下载/配置 llama.cpp，生成目标机自己的运行时配置。不要从其他电脑照搬本机 `runtime_config.json` 或包含绝对路径的运行时状态。模型自行准备到共享目录：

```text
ComfyUI/models/LLM/Qwen3.8
```

节点按完整 GGUF 文件名选择语言模型和 `mmproj` 投影；目录中的优先模型名为 `Qwen3.8-27B-UD-Q4_K_M.gguf` / `Qwen3.8-27B-Q4_K_M.gguf`，投影优先 `mmproj-F16.gguf`。兼容性仍需按实际模型与运行时检查。

Qwen 全片导演只做文本规划，不运行 H3；规划完成后仍需人工确认。完整 `final` 提示词直接使用，不重新扩写；旧外部提示词小助手仍由其自身规则控制。本地时间、台词及音频边界以已确认项目为准。

## 数据与质量检查

项目与分段保存在 `ComfyUI/output/TYH3LongVideo/projects`，成片在 `ComfyUI/output/TYH3LongVideo/final_videos`，规则在 `ComfyUI/user/default/TYH3LongVideo`。这些内容不包含在仓库中，保留完整项目才便于继续重做和合成。

ASR 首次下载、人声分离依赖、FFmpeg 与 ffprobe 的配置见[安装与迁移](安装与迁移.md)。唱歌识别可能出错，建议先校对台词与切点；镜头规划和参考图约束均需检查实际成片，不保证段间无缝。
