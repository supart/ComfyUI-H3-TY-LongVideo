# 阶段说明

版本标识：`v0.1.0-beta.1`。这是 TY 分支首次整理的预发布版本，面向已有 H3 环境的 Windows 用户。项目基于 [Zzz1phyrf/ComfyUI-H3-LongVideo](https://github.com/Zzz1phyrf/ComfyUI-H3-LongVideo) 二次开发。

## 当前能力

- TY Shot Planner：视频上传与截取、带音轨视频分析、波形/源视频预览、切点调整、切割与合并、参考图素材库、逐段生成与批量生成。
- 生成管理：当前段结束后暂停、停止后续任务、单段重做、保留成功旧版、恢复上一版、重新合成。
- 长音频：唱歌、口播、居中演讲分段；本地规则和可选 Qwen 全片导演；逐段参考图与音频回配。

保留三个节点 ID、现有输入输出和路由：`TY_ShotPlanner`、`TY_H3LVUnified`、`TY_H3LVDirectorTask`。本次只整理预发布文档与仓库内容，运行代码、前端、规则和测试与 2026-10-25 已验证阶段版本相同。

## 本次预发布

SelfLift 示例保留已调参数、排版和连线，清空素材选择、旧项目绑定、分段索引与输出预览，便于在目标机重新选择素材。文件名保留原整理日期，不表示另一个功能版本。

本预发布快照及附件保留运行模块、前端、默认规则、依赖声明、已有运行时安装脚本、第三方许可和回归测试；不包含本机配置、二进制运行时、模型、私人素材、项目、成片或私有开发历史。旧开发仓库的其他分支与历史单独保留为私有存档。不新增安装器。

`requirements.txt` 保留 `faster-whisper==1.2.1` 并声明 SoundFile；已有 Torch/CUDA 环境不由本预发布替换。

## 与上游的区别

当前 TY 使用自己的节点 ID 与 `TYH3LongVideo` 数据目录，主要新增源视频分段与 SelfLift 集成。上游后续的外部 API 提示词生成器、`segment_material` 接口、原生 `CreateVideo → SaveVideo` 保存链路及统一错误日志下载，不属于本预发布功能。当前 TY 顺序生成仍使用 VHS。

## 使用限制

源视频必须带声音；无声视频当前会明确失败。浏览器预览支持与 FFmpeg 解码能力不同，某些编码可能无法预览。

自动识别与分段仍需试听校对；人物身份、衣着、动作和段间衔接需检查实际成片。旧项目、模型和素材不会随插件包自动迁移。

只记录本机外部节点的参考版本，不保证任意后续版本的节点接口兼容。主项目未附整体开源许可证，本次预发布未新增开源授权；外部依赖与模型仍适用各自授权。
